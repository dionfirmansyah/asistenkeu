# Kode Rapi

Sumber kebenaran: `references/standar.md` (milik user — bebas diubah kapan saja,
aturan di sana mengalahkan default skill ini).

## Workflow wajib sebelum koding

1. Baca `references/standar.md` sampai selesai.
2. Baca `references/audit-lanjutan.md` bila menyentuh file yang terdaftar di sana.
3. Terapkan aturannya pada setiap edit; bila aturan standar konflik dengan
   kebutuhan nyata, ikuti kebutuhan nyata dan catat pengecualiannya di respons.
4. Setiap menyentuh library pihak ketiga, wajib ikuti aturan Context7 di
   `references/standar.md` — jangan tulis kode dari hafalan API.
